# Contributing

plateau-ui is in alpha and looked after by one person, so a reply can take a while.

plateau-ui はアルファ版で、ひとりで管理しています。返事に時間がかかることがあります。

## Issues

Welcome, in Japanese or English: something that does not work, a place the documentation is wrong, something
you could not do. For a bug, say what you expected, what you saw, the browser, and whether the map was drawn
with WebGPU or WebGL2 (`viewer.backend` says which).

不具合、ドキュメントの誤り、できなかったことなど、日本語でも英語でもどうぞ。不具合のときは、期待したこと、
実際に起きたこと、ブラウザ、WebGPU と WebGL2 のどちらで描かれていたか（`viewer.backend`）を書いてください。

## Pull requests

This repository does not take pull requests. The code is open to read, use and change under the MIT License,
and a change you would like to see here is best told as an issue.

このリポジトリではプルリクエストを受け付けていません。コードは MIT ライセンスのもとで自由に読み、使い、
変えることができます。ここに入れてほしい変更は Issue で知らせてください。
